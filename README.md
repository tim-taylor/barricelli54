# barricelli54
A C++ implementation of Nils Aall Barricelli's computational worlds as
described in his 1954 paper _Esempi Numerici di Processi di Evoluzione_.
The program regenerates each of the figures shown in the paper.

## Compilation
The source code is a single C++ file `barricelli.cpp` that lives in the `src` directory. It should be compiled with a C++20 (or later) compiler.

For Linux users, the `compile` script in the base directory should
compile the source code for you. The output is an executable file
`barricelli54` that lives in the base directory.

## Use
Once compiled, the program can be run with the command:
```
barricelli54 [-c] n
```
where `n` is the figure number to be reproduced, and the `-c` flag,
if present, specifies that output should be in CSV format. If the `-c`
flag is omitted, the output is space-separated and padded so columns
of digits are aligned.

## Converting CSV files to images
To convert the CSV files generated by the `barricelli54` program into
images that match the style of those presented in Barricelli's 1954
paper, the `csv2img.py` script is provided in the `tools` directory.

This can be run as follows:
```
python3 csv2img.py [-b] [-f png|pdf|svg] my_csv_file.csv [label_specs...]
```
where `my_csv_file.csv` is a CSV file such as those generated by
`barricelli54`. The `-b` flag, if present, specifies that grid lines
should be included in the output. The `-f` flag selects the output
image format — `png`, `pdf`, or `svg` — and defaults to `pdf` if
omitted; `pdf` and `svg` are vector formats, with `pdf` being the
most convenient to include in a LaTeX document via `\includegraphics`.
One or more `label_specs` can optionally be specified to print labels
above and/or below the generated image at specified positions. See
the `csv2img.py` file for details of usage.

The script produces an image file with the same basename as the
specified CSV file and an extension matching the chosen format
(e.g. `my_csv_file.pdf`).

A Bash script `gen-figs-with-labels`, also in the `tools` directory,
generates Figures 8-11 with the labels as they appear in the 1954
paper. It takes an optional format argument (`png`, `pdf`, or `svg`,
defaulting to `pdf`) that is passed through to `csv2img.py`:
```
./gen-figs-with-labels [png|pdf|svg]
```
